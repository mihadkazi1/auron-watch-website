# Production 3D watch asset

Place the final optimized watch file here as `watch.glb` when you are ready.

The website is designed to load a production GLB through `VITE_WATCH_MODEL_URL=/models/watch.glb`. The current default scene is procedural so the site works before the final asset is selected.

For the Unity/Vuforia build, keep the same source asset but author it with separate meshes for the exterior and movement components.
